# Scientific references and attribution

Software reorganization, tests and bug fixes do not establish priority for an existing scientific method. Cite only the methods and source implementations actually used in your analysis, alongside this software's version/commit.

- Nili H, Wingfield C, Walther A, Su L, Marslen-Wilson W, Kriegeskorte N (2014). **A Toolbox for Representational Similarity Analysis.** PLOS Computational Biology 10(4):e1003553. [Published article](https://doi.org/10.1371/journal.pcbi.1003553). RSA toolbox foundations; condition-RDM comparison and Kendall tau-a. The paper's original Software S1 archive is distinct from later develop/fork snapshots.
- Su L, Zulfiqar I, Jamshed F, Fonteneau E, Marslen-Wilson W (2014). **Mapping tonotopic organization in human temporal cortex: representational similarity analysis in EMEG source space.** Frontiers in Neuroscience 8:368. [Published article](https://doi.org/10.3389/fnins.2014.00368), also citing prior Su et al. (2012) work. The article explicitly describes use of an MEG/EEG toolbox extension. The present development release does not claim first publication of this method.
- Walther A, Nili H, Ejaz N, Alink A, Kriegeskorte N, Diedrichsen J (2016). **Reliability of dissimilarity measures for multi-voxel pattern analysis.** NeuroImage 137:188–200. [Article DOI](https://doi.org/10.1016/j.neuroimage.2015.12.012). Crossvalidated dissimilarity and noise normalization; an implemented identity precision should not be described as estimated whitening.
- Maris E, Oostenveld R (2007). **Nonparametric statistical testing of EEG- and MEG-data.** Journal of Neuroscience Methods 164:177–190. [Article DOI](https://doi.org/10.1016/j.jneumeth.2007.03.024). Exchangeability and spatiotemporal cluster inference.
- Smith SM, Nichols TE (2009). **Threshold-free cluster enhancement: addressing problems of smoothing, threshold dependence and localisation in cluster inference.** NeuroImage 44:83–98. [Article DOI](https://doi.org/10.1016/j.neuroimage.2008.03.061). TFCE. This release specifies a finite-graph integral, extent .5 and height 2; see METHODS.md.
- Benjamini Y, Hochberg Y (1995). **Controlling the False Discovery Rate: A Practical and Powerful Approach to Multiple Testing.** Journal of the Royal Statistical Society, Series B (Methodological), 57:289–300. [Article DOI](https://doi.org/10.1111/j.2517-6161.1995.tb02031.x). BH adjustment, which is separate from maximum-statistic FWER correction.

Application provenance: the [2017 phonetic mapping paper](https://doi.org/10.1371/journal.pcbi.1005617) and [2022 DNN mapping paper](https://doi.org/10.3389/fncom.2022.1057439), with their pinned LiSuLab repositories in `provenance/source-lock.json`. Research-specific model training, word labels, public data exports and analysis choices are not automatically reproduced by a general toolbox example.

Current alternatives include [CoSMoMVPA](https://cosmomvpa.org/), [MNE-RSA](https://mne.tools/mne-rsa/stable/index.html), and [Python rsatoolbox](https://github.com/rsagroup/rsatoolbox). Compare concrete supported estimators, modalities and validation conditions; do not state that other RSA packages only support fMRI.
